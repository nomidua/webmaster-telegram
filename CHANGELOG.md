# Changelog

## 1.1
- Защита от дублей: для уже отправленной записи — «В Telegram ещё раз» с подтверждением и датой; массовая отправка пропускает отправленные.
- Предупреждение в админке, если автопостинг не может отправить пост (токен, права, канал) или крон не запускался больше 30 мин.
- ✓ в колонке — ссылка на пост в канале.
- «Отправить сейчас» у кандидатов в блоке «Сейчас».
- Экспорт/импорт настроек в JSON (без токена, канала и тестового чата; рубрики по слагу).

## 1.0
- Первая версия: пост с фото, заголовком, анотацией, хештегами и кнопкой по языку записи; UTM; тихие сообщения.
- Отбор «Только популярные» (просмотры в час) или «Все по очереди», исключение рубрик.
- Расписание по дням недели, часы, дневной максимум, пауза между постами.
- Живое превью, тест в личку, проверка подключения.
- Ручная и массовая отправка из списка записей, колонка-статус.
- Журнал, пауза при общих ошибках, обновления из GitHub.
