# WebMaster Telegram

Автопостинг записей WordPress в Telegram-канал. Всё настраивается в самом плагине, с живым превью поста.

## Что умеет

- **Пост**: фото записи (уменьшается до 1280 px, JPEG), **жирный заголовок**, пустая строка, анотация (отрывок) или первые ~200 знаков текста, до 2 хештегов из меток, кнопка «Читать» / «Читати» по языку записи (поле `post_lang`).
- Ссылка спрятана в кнопке, к ней добавляются UTM-метки (по умолчанию `utm_source=telegram&utm_medium=social&utm_campaign=channel`).
- Все сообщения — без звука (отключаемо).
- **Отбор**: «Только популярные» — из записей за вчера и сегодня в каждый слот уходит та, у которой больше просмотров в час (после ожидания 60 мин), или «Все по очереди». Исключение рубрик.
- **Просмотры**: Post Views Counter, если установлен; иначе поле записи (`post_views_count` у темы Newspaper).
- **Расписание**: по дням недели — включён/выключен, часы «с–до», максимум постов в день; пауза между постами (40 мин).
- **Тест в личку**: «Найти мой чат» + «Отправить тест мне» — приходит точно такой пост, как в канал.
- **Ручная отправка**: ссылка «В Telegram» в списке записей, массовое действие (до 10), «Отправить сейчас» у кандидатов. Узкая колонка-статус ✓ / ! (✓ ведёт на пост в канале).
- **Защита от дублей**: повторная отправка только через «В Telegram ещё раз» с подтверждением; массовая отправка пропускает отправленные.
- **Предупреждения в админке**, если бот не может публиковать или крон не запускался больше 30 мин.
- **Перенос настроек** на другой сайт: экспорт/импорт JSON без токена и канала, рубрики сопоставляются по слагу.
- **Журнал** последних 200 событий, проверка подключения (бот — администратор канала с правом публикации).
- Ошибки сети, токена или прав канала ставят автопостинг на паузу 15 мин и не помечают запись; после 3 ошибок самой записи она пропускается.
- Отправляются только записи, опубликованные после активации плагина — старые не «вываливаются» в канал.
- Обновления из GitHub Releases прямо в «Плагинах».

## Установка

1. Плагины → Добавить → Загрузить `webmaster-telegram.zip` → Активировать.
2. Настройки → WebMaster Telegram: токен бота из @BotFather, канал `@username`, «Проверить подключение».
3. Откройте бота в Telegram → Start → «Найти мой чат» → «Отправить тест мне».
4. Включите «Автопостинг» и сохраните.

Бот должен быть администратором канала с правом «Публиковать сообщения». Токен храните только в настройках плагина.

## Требования

WordPress 6.2+, PHP 7.4+. Нужен работающий WP-Cron или серверный крон (проверка каждые 5 мин).

## Удаление

При удалении плагина стираются его настройки, журнал и служебные метки записей (`_wmtg_*`).
